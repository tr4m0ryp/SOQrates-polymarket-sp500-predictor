All input data comes from free public APIs, cited where used: the Yahoo
chart API and stooq for futures and index series
\citep{yahoo2026chartapi,stooq2026spx}, Slickcharts and Nasdaq's
listed-securities file for index weights and venue tags
\citep{slickcharts2026sp500,nasdaqtrader2026listed}, Polymarket's gamma and
CLOB APIs for market odds and price curves
\citep{polymarket2026gamma,polymarket2026clob}, GDELT DOC 2.0 for news
\citep{gdelt2017doc}, the FRED release-dates API for the macro calendar
\citep{fred2026releasedates}, and free Nasdaq TotalView-ITCH and NYSE TAQ
sample days for the auction feeds
\citep{nasdaq2026itchsamples,nyse2026taqimbalances}. The implementation is
a private repository under a noncommercial license, available from the
author on reasonable request.
