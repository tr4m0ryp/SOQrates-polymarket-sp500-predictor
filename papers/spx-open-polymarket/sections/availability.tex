All input data comes from free public APIs, cited where used. Futures and
index series come from the Yahoo chart API and stooq
\citep{yahoo2026chartapi,stooq2026spx}. Index weights and venue tags come
from Slickcharts and Nasdaq's listed-securities file
\citep{slickcharts2026sp500,nasdaqtrader2026listed}. Market odds and price
curves are read from Polymarket's gamma and CLOB APIs
\citep{polymarket2026gamma,polymarket2026clob}, news from GDELT DOC 2.0
\citep{gdelt2017doc}, and the macro release calendar from the FRED
release-dates API \citep{fred2026releasedates}. The auction feeds were
measured on free Nasdaq TotalView-ITCH and NYSE TAQ sample days
\citep{nasdaq2026itchsamples,nyse2026taqimbalances}. The implementation is
a private repository under a noncommercial license, available from the
author on reasonable request.
